2. Dépose
Lever et caler le véhicule, roues arrière pendantes.
Figure : b3fp124c
Déposer :
  • Le contre-écrou ( 1)
  • L’écrou (2)
  • L’entretoise (3)
  • Le palonnier (4)
Désaccoupler le tube (5).
NOTA : Obturer les embouts des raccords hydrauliques.
Figure : b3dp07tc
Déposer les pattes de fixation ( 6).
Figure : b3dp07uc
Déposer la goupille (8).
Désaccoupler la biellette (7).
Caler le bras de suspension pour le maintenir approximativement dans sa position avant de déposer l’amortisseur.
Figure : b3dp07vc
Déposer :
  • Les vis supérieures d’amortisseurs ( 9)
  • Les ressorts de suspension
Figure : b3dp07wc
Déposer :
  • Les vis (10)
  • La traverse d’essieu arrière
3. Repose
IMPERATIF : Placer le véhicule roues au sol avant d’effectuer le serrage au couple des vis ( 10).
IMPERATIF : Remplacer la goupille ( 8).
Repose :
  • Les semelles caoutchouc
  • La traverse d’essieu arrière
Figure : b3dp07xc
Centrer la traverse d’essieu arrière À l’aide des outils [1].
Reposer :
  • Les vis (10)
  • Les ressorts de suspension
  • Les amortisseurs
  • Les vis (9)
Accoupler :
  • La biellette (7)
  • Le tube
Reclipper le tube ( 5) sur la traverse d’essieu arrière.
Reposer :
  • Les pattes de fixation ( 6)
  • Le palonnier (4)
  • L’entretoise (3)
  • L’écrou (2)
  • Le contre-écrou (1)
Serrer les vis (10) à 12 ± 1 m.daN .
Déposer les outils [1].
Figure : b2gp00pc
Charger le véhicule afin d’obtenir la cote : H = 620 mm .
Serrer les vis (9) à 17 ± 1,7 m.daN .
Purger les freins (voir opération correspondante).
Régler le frein de stationnement (voir opération correspondante).
