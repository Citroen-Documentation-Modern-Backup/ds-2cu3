B3EG07P0Dépose - repose : Colonne de direction
1. Opérations préliminaires
Débrancher la borne négative de la batterie.
Déposer le volant de direction (voir opération correspondante).
2. Dépose
Figure : b3ep00rc
Déposer :
  • Les vis (2)
  • Les vis (1)
  • Le cache inférieur (3)
Figure : b3ep00sc
NOTA : Les vis ( 1) fixent également le cache supérieur (4).
Déposer le cache supérieur ( 4).
Figure : b3ep00tc
Déposer :
  • Les vis (5)
  • La vis (7)
  • La garniture inférieure (6)
Figure : b3ep00uc
Débrancher les connecteurs des commandes sous volant ainsi que ceux de l’antivol de direction.
Désolidariser le câble d’ouverture du capot moteur Effectuer les opérations suivantes.
Débrider le câble dans le compartiment moteur.
Déposer l’obturateur caoutchouc sur le levier de commande.
Désolidariser le câble de sa commande.
Repousser la gaine du support de commande.
Figure : b3ep00vc
Déposer les vis ( 8) sur le plancher.
Figure : b3ep00wc
Déposer l’écrou ( 9) et la vis de maintien du cardan sur la crémaillère.
Figure : b3ep00xc
Déposer :
  • Les vis (11)
  • Les écrous (10)
  • Déposer la colonne de direction
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Reposer le volant de direction (voir opération correspondante).
ATTENTION : Lors de la pose du volant de direction, veiller au bon positionnement de l’index de rappel automatique de la commande de clignotant sur la base du volant de direction.
IMPERATIF : Remplacer systématiquement les écrous Nylstop.
Serrer :
  • L’écrou (9) à 4,5 m.daN
  • Les vis (11) à 1 m.daN
  • Les écrous (10) à 1 m.daN
Brancher la batterie.
