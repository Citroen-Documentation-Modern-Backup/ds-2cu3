3. Repose
Figure : b3dp00vc
Reposer :
  • La fusée (5)
  • Les vis (4) Avec l’outil [4]
Serrage à 15 m.daN.
Figure : b3dp00wc
Reposer :
  • Le moyeu (3)
  • L’écrou (2)
Utiliser un écrou neuf Serrer à 2 m.daN.
Tourner le moyeu de 3 tours.
Poser l’outil [3] Le fixer sur la lame de ressort à l’aide d’un serre-joint ou d’une pince étau.
Poser les outils [2]-[1].
Régler le jeu du moyeu (3). Desserrer ou serrer l’écrou (2).
Le jeu doit être compris entre 0,025 mm et 0,10 mm.
Figure : b3dp00xc
Freiner l’écrou (2) Avec l’outil [5].
Le méplat "a" de l’outil doit toujours être dirigé vers l’extérieur.
Figure : b3dp00yc
ATTENTION : La jupe de l’écrou doit être freinée dans le sens opposé au serrage.
