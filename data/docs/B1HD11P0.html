3. Contrôle
IMPERATIF : Respecter les conditions de contrôle suivantes : Moteur à température de fonctionnement. Véhicule en état de marche. Moteur pleine charge.
3.1. Préparation
Figure : b1bp231d
Déposer le collier (1).
Interposer l’outil [ 2] muni de l’outil [3], entre le tube (3) et le conduit (2).
Positionner l’outil [ 1] dans le véhicule.
Raccorder le manchon [ 2] sur le manomètre [1] avec tube "a".
3.2. Mode opératoire
Figure : c5fp08ac
Démarrer le moteur.
Engager le rapport de 1ère vitesse, et démarrer le véhicule.
Engager les rapports jusqu’au 3ème rapport.
Décélérer jusqu’à un régime de 1000 tr/mn.
Contrôler la pression : La valeur de pression correcte doit être de 0,6 ± 0,05 bars (1500 tr/mn).
Accélérer franchement en reprise (passage du 4ème rapport au 3ème rapport).
Contrôler la pression : La valeur de pression correcte doit être de 0,9 ± 0,05 bars (entre 2500 et 3500 tr/mn).
Déposer les outils [ 1], [2]et [3].
Repositionner le tube ( 3).
Remettre le collier ( 1).
