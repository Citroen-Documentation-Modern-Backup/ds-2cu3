C5HG1BP0Dépose - repose : Évaporateur
REFRIGERATION SIMPLE OU REFRIGERATION DOUBLE
1. Dépose
Déposer (voir opérations correspondantes) :
  • La planche de bord
  • Le groupe de chauffage
  • Thermostat antigivre
Figure : c5hp10nd
Déconnecter :
  • La résistance (3)
  • Le pulseur d’air (5)
Déposer :
  • Le tableau de commande ( 11)
  • Le boîtier d’entrée d’air (1)
  • La vis (8)
Désaccoupler les câbles de volet ( 2), (10) et (6).
Déboîter la commande ( 7).
Déposer :
  • Le carter (4)
  • Le radiateur (9)
  • Le groupe de relais (12)
Figure : c5hp10pc
Déposer le carter (13).
Figure : c5hp10qc
Décoller délicatement le joint ( 14) (jusqu’à la jonction "A" des deux demi-carters) À l’aide d’un outil coupant (15).
Figure : c5hp10rd
Déposer les vis de fixation (suivant flèches).
Désaccoupler les deux demi-carters.
Figure : c5hp10sc
Dégager l’ensemble détendeur ( 16)/évaporateur (17) (suivant flèche ).
Figure : c5hp10tc
Désaccoupler les raccords (18).
NOTA : Obturer rapidement tous les conduits afin d’éviter l’introduction d’humidité.
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
2.1. Climatisation
N’utiliser que des joints neufs.
Lubrifier les joints neufs avec de l’huile pour compresseur.
Serrer les raccords en utilisant une contre-clé.
2.2. Groupe de chauffage
Figure : c5hp10ud
Effectuer les opérations suivantes :
  • Nettoyer soigneusement les portées des deux demi-carters
  • Déposer un fin cordon de pâte AUTO JOINT CLAIR (E13) sur la portée
  • Accoupler les deux demi-carters
  • Vérifier le fonctionnement de tous les volets d’ouverture/fermeture
  • Poser les vis de fixation et les serrer
Figure : c5hp10vc
Effectuer les opérations suivantes :
  • Nettoyer la portée du joint ( a)
  • Poser des pointes de colle ou du double face sur la portée du joint (a)
  • Poser le joint (14)
  • Exercer une pression sur le joint
Figure : c5hp10wc
Reposer :
  • Le groupe de chauffage (partiellement avec 2 écrous côté habitacle)
  • Le joint (19)
  • Les écrous (22) (côté moteur)
Accoupler :
  • Le raccord du tuyau basse pression ( 21)
  • Le raccord du tuyau haute pression (20)
Effectuer un tirage au vide pendant 15 minutes (valves (23) et (24)).
Vérifier l’étanchéité du circuit par les manomètres de la station de charge.
