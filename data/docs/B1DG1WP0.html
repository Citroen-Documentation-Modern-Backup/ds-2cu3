2. Dépose
Déconnecter le câble négatif de la batterie.
Lever et caler le véhicule.
Déposer les protections sous moteur.
Vidanger le circuit de refroidissement (voir opération correspondante).
Figure : b1dp01mc
Déposer :
  • Le support réservoir de direction assistée
  • Les conduits d’air (2)
  • Le collecteur d’admission (1)
  • Le turbocompresseur (voir opération correspondante)
NOTA : (*) Suivant équipement.
Désaccoupler :
  • Les durits de chauffage (sur culasse)
  • La durit de pompe à vide
  • La durit (3)
  • La durit (4) (sur culasse)
  • Les tuyaux du réchauffeur de gazole
Déposer :
  • Le dessus du réchauffeur de gazole
  • Les 3 vis du boîtier de sortie d’eau
  • Les tuyaux injecteurs
Débrancher :
  • L’alimentation des bougies de préchauffage
  • Le fil de la bougie de préchauffage du cylindre numéro 1
Déposer :
  • La courroie de distribution (voir opération correspondante)
  • Les vis de culasse
  • La culasse
3. Repose
3.1. Généralités
Nettoyer les plans de joints (ne pas utiliser d’outil tranchant ou abrasif).
Contrôler la planéité de la culasse : Déformation maximale admise = 0,03 mm.
Mesurer le dépassement de chaque piston au Point Mort Haut (si nécessaire).
Passer un taraud dans les taraudages des vis de culasse du carter-cylindres (12x150).
Souffler de l’air comprimé sur les différents taraudages du carter-cylindres.
3.2. Culasse
Figure : b1dp01nc
Contrôler la présence de la bague de centrage (5).
Poser :
  • L’outil [1a]
  • Le joint de culasse
  • La culasse
  • Les vis de culasse
Déposer l’outil [1a] , À l’aide de l’outil [1b].
Serrer les vis de culasse dans l’ordre indiqué (voir opération correspondante).
NOTA : Il n’est pas nécessaire de resserrer la culasse après mise en température du moteur.
3.3. Repose
Poser la courroie de distribution (voir opération correspondante).
Brancher les fils d’alimentation des bougies de préchauffage.
Poser :
  • Les tuyaux injecteurs
  • Les 3 vis du boîtier de sortie d’eau
  • Le dessus du réchauffeur de gazole
Accoupler :
  • Les durits du circuit de refroidissement
  • La durit de pompe à vide
  • Les tuyaux du réchauffeur de gazole
Poser :
  • Le turbocompresseur (voir opération correspondante)
  • Le collecteur d’admission (1)
  • Les conduits d’air
  • Le support réservoir de direction assistée
  • Les protections sous moteur
NOTA : (*) Suivant équipement.
Rebrancher la batterie.
Remplir :
  • Le réservoir de direction assistée (si nécessaire)
  • Le circuit de refroidissement
Purger le circuit de refroidissement (voir opération correspondante).
Mettre le moteur en marche.
Manoeuvrer lentement la direction de butée à butée pour purger le vérin . Compléter le niveau (si nécessaire).
Replacer le véhicule sur le sol.
