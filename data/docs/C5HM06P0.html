1. Groupe de chauffage additionnel
Débrancher la borne négative de la batterie.
Mettre le véhicule sur un pont élévateur.
Figure : c4ap11fc
Désaccoupler le tube d’échappement du collier ( 1).
Déconnecter le connecteur (2).
Vidanger le liquide de refroidissement par les 2 raccords (3) : Prévoir l’écoulement du liquide.
ATTENTION : Introduire rapidement un bouchon dans les tubes (côté moteur).
Désaccoupler le tube d’alimentation carburant du collier ( 4) : Prévoir l’écoulement du liquide.
ATTENTION : Introduire rapidement un bouchon dans le tube (côté moteur).
Figure : c5hp11zc
Déposer :
  • Les 6 vis (5)
  • La ferrure de soutien
Figure : c5hp120c
Déposer :
  • Le collier (6)
  • Les vis (7)
  • Le groupe de chauffage additionnel
Figure : c5hp121c
