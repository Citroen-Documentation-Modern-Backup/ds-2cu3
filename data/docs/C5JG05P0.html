C5JG05P0Dépose - repose : Pare-chocs avant
1. Déposer
Déposer la calandre (voir opération correspondante).
Figure : c5jp00gc
Déposer les écrous ( 1) de fixation du pare-chocs avant (de chaque côté).
Les écrous sont situés derrière les écrans pare-boue (ne pas déposer ceux-ci).
Figure : c5jp00hc
Déposer :
  • Les cache-vis ( 2) (en faisant levier avec un tournevis)
  • Les vis de fixation
  • Les vis (3)
Déposer le pare-chocs (en le tirant vers l’avant).
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
