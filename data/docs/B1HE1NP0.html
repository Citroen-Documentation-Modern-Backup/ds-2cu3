Lever et caler le véhicule.

  • Le cache-style

Figure : b1hp16uc
Équiper le comparateur [3] de la touche [5].
Placer le comparateur sur le support [ 4].
Positionner cet ensemble dans l’orifice de calage.
Figure : b1bp226c
Approcher la poulie de pompe d’injection ( 7) de son point de calage.
Tourner le moteur en arrière et rechercher le point mort bas du piston de la pompe d’injection jusqu’à ce que l’aiguille du comparateur [ 3] ne bouge plus.
Étalonner le comparateur à zéro.
Figure : b1bp227c
Tourner le moteur dans le sens normal de rotation jusqu’à ce que l’outil [ 2] s’engage dans le trou de pigeage de la poulie de pompe d’injection (7) (suivant flèche ).
Le moteur étant au PMH, la valeur lue sur le comparateur (après le PMB pompe d’injection) doit être
Moteur Valeur lue
2.8 D X = 0,94 ± 0,05 mm
2.8 TDi X = 1,10 ± 0,05 mm
Si la valeur lue sur le comparateur n’est pas correcte, réaliser un nouveau calage.
Déposer les outils [ 2], [3],[4]et [5].
Reposer :
  • Les écrous (6) Serrer à 2,5 ± 0,2 m.daN
  • Le bouchon (5) de l’orifice de calage
  • Les canalisations d’injection , Serrer à 2,5 ± 0,2 m.daN
  • Le carter de distribution (3)
  • Les vis (4)
  • La vis (2) du levier d’avance (si nécessaire)
  • Le cache-style
Rebrancher la batterie.
Remettre le véhicule sur ses roues.
4. Calage statique de la pompe à injection
Piger la poulie de la pompe d’injection à l’aide de l’outil [ 2].
Figure : b1bp225c
Desserrer :
  • Les canalisations d’injection
  • Les écrous (6)
Figure : b1bp1y7c
Basculer la pompe en position retard vers l’extérieur du moteur.
Tourner lentement la pompe dans le sens avance (vers le moteur) jusqu’à ce que le comparateur affiche la cote X.
Lorsque le comparateur affiche la cote X correspondante, serrer les écrous (6) à 2,5 ± 0,2 m.daN.
ATTENTION : Au cours du serrage, l’aiguille du comparateur ne doit pas bouger.
Contrôler le calage.
Déposer les outils [ 2], [3],[4]et [5].
Reposer :
  • Le bouchon ( 5) de l’orifice de calage
  • Les canalisations d’injection , Serrer à 2,5 ± 0,2 m.daN
  • Le carter de distribution (3)
  • Les vis (4)
  • Le cache-style
Rebrancher la batterie.
Remettre le véhicule sur ses roues.
