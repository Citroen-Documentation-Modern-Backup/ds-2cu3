1. Opérations préliminaires
Déshabillage : Boîte de vitesses .
Dépose : Couple de 5ème.
Dépose : carter de boîte de vitesses.
Dépose : Arbres primaire, secondaire et différentiel.
2. Déshabillage
Figure : b2cp08sc
Placer l’arbre secondaire (1) dans un étau équipé de mordaches (2).
Figure : b2cp08xc
Extraire le roulement ( 3) à l’aide des outils [16] et [31].
Figure : b2cp08yc
Déposer :
  • Le pignon récepteur (4ème) (4)
  • Le synchroniseur de 3ème/4ème (5)
  • Les 2 bagues du synchroniseur
Figure : b2cp08tc
Déposer :
  • Le jonc d’arrêt (6) À l’aide de l’outil [12]
  • Le pignon récepteur (3ème) (7)
Figure : b2cp08uc
Déposer :
  • Le jonc d’arrêt (8) À l’aide de l’outil [12]
  • Le pignon récepteur (2ème) (9)
  • Le synchroniseur de 1ère/2ème (10)
Figure : b2cp08vc
Déposer :
  • Le jonc d’arrêt (11) À l’aide de l’outil [12]
  • Le pignon récepteur (1ère) (12)
Figure : b2cp08zc
Déposer la butée (13).
Figure : b2cp090c
Déposer le jonc d’arrêt ( 14), à l’aide de l’outil [12].
Figure : b2cp091c
Extraire la cage intérieure du roulement ( 15) à la presse, à l’aide de l’outil [31].
3. Habillage
Figure : b2cp092c
Poser le roulement à galets cylindriques ( 15) à la presse, avec le tube de montage [13].
Poser le jonc d’arrêt ( 14), à l’aide de l’outil [12].
Poser la butée ( 13).
Poser :
  • Le pignon récepteur (1ère) (12)
  • Le jonc d’arrêt (11) À l’aide de l’outil [12]
  • Le synchroniseur de 1ère/2ème (10) (engager les 3 pattes du synchroniseur-double, dans les embrèvements du pignon)
  • Le pignon récepteur (2ème) (9)
  • Le jonc d’arrêt (8) À l’aide de l’outil [12]
ATTENTION : Il y a 2 possibilités d’épaisseur du jonc d’arrêt : 2,25 mm ou 3,50 mm.
Poser :
  • Le pignon récepteur (3ème) (7)
  • Le jonc d’arrêt (6) À l’aide de l’outil [12]
  • Le synchroniseur de 3ème/4ème (5)
  • Les 2 bagues du synchroniseur
  • Le pignon récepteur (4ème) (4)
Figure : b2cp093c
Reposer la cage intérieure du roulement ( 3) à la presse, à l’aide de l’outil [14].
