B3GG0EP0Dépose - repose : Bloc hydraulique ABS
ANTI-BLOCAGE ROUE
1. Outillage préconisé
Un presse pédale.
2. Dépose
Débrancher la borne négative de la batterie.
Figure : b1dp09wc
Déposer :
  • Les vis (1)
  • Les écrous (3)
  • La protection sous moteur (2)
Figure : b3gp01yc
Déconnecter le connecteur (4).
Placer le presse pédale sur la pédale de frein, afin d’éviter l’écoulement du liquide de frein lors du désaccouplement des tubes de frein.
Figure : b3gp01zc
Désaccoupler :
  • Les raccords (5)
  • Les raccords (6)
Figure : b3gp020c
Ouvrir l’agrafe ( 7).
ATTENTION : Veiller à ne pas déformer les tubes hydrauliques.
Déposer :
  • Les fixations du bloc hydraulique ABS
  • Le bloc hydraulique ABS
ATTENTION : Obturer les orifices .
3. Repose
NOTA : Le bloc hydraulique est livré rempli de liquide de frein.
IMPERATIF : Enlever les obturateurs des orifices du bloc hydraulique ABS.
Reposer :
  • Le bloc hydraulique ABS
  • Les fixations du bloc hydraulique ABS
Accoupler :
  • Les raccords (6) : Serrer à 1,6 m.daN
  • Les raccords (5) : Serrer à 1,6 m.daN
Refermer l’agrafe (7).
Vérifier que les tubes hydrauliques ne sont pas en contact avec la caisse.
Reconnecter le connecteur (4).
Déposer le presse pédale.
Purger le circuit de freinage (voir opération correspondante).
Reposer :
  • La protection sous moteur (2)
  • Les vis (1)
  • Les écrous (3)
