C5JG06P0Dépose - repose : Pare-chocs arrière
1. Dépose
1.1. Élément arrière latéral
Figure : c5jp00ic
Ouvrir la porte arrière.
Déposer :
  • La vis (1)
  • Le feu arrière (voir opération correspondante)
Figure : c5jp00jc
Déposer les vis de fixation extérieures ( 2).
Figure : c5jp00kc
Déposer l’élément (en le tirant vers l’arrière).
1.2. Élément arrière inférieur
Figure : c5jp00lc
Desserrer les écrous ( 4) sur les 2 pattes de fixation, par le dessous du véhicule.
Déposer les vis (3).
Figure : c5jp00mc
Déposer l’élément (en le tirant vers l’arrière).
1.3. Élément sur bas de porte
Figure : c5jp00nc
Faire glisser l’élément le long de la porte (vers le centre du véhicule).
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
